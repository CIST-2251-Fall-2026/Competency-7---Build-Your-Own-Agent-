During my initial testing, the agent repeatedly searched for the same information without completing the task. The retrieval function was returning unrelated passages, which made it difficult for the model to find the correct information. I improved the retrieval function by adding overlapping chunks, removing common search words, and giving relevant documents higher scores. I also added duplicate-action prevention and a fallback for generating a final answer. After testing these changes, the agent successfully retrieved the radius of Mars. However, during another test, it confused the radius of Mars with its diameter. This was a model reasoning error rather than a retrieval error. From the customer's perspective, incorrect calculations and repeated searches could reduce trust in the assistant. The agent needs to provide accurate information while avoiding unnecessary tool calls and stopping safely when it cannot answer a question.
I used OpenAI's ChatGPT to assist with  improving the agent. AI assistance included revising Python code, improving document retrieval, troubleshooting Ollama, preventing repeated tool calls, and organizing the project. I implemented the code in VS Code, ran the tests locally, reviewed the results, and examined the trajectory logs to identify problems and evaluate the agent's performance.
